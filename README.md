# VERITY // THE ARCHIVE

An independent, spoiler-rich investigative fan site exploring **ThatMob's VERITY**, the 2026 scripted Minecraft horror film.

**Intended live URL:** https://cachenetworks.github.io/VerityStory/

> ⚠️ Contains full-film spoilers and discussion of the story's fictional suicide ending.

## What's inside

- A cinematic, mobile-first landing page and optional spoiler entry screen.
- Episode-by-episode story summaries and release dates.
- A reconstructed timeline with **published / character claim / theory** classifications.
- Characters and an eight-piece interactive evidence locker.
- Twelve searchable, filterable theories with supporting and contradicting evidence.
- AGI, consciousness and AI safety analysis with a reality check.
- Nine open mysteries, creator credits, source links, keyboard navigation, and reduced-motion support.
- No backend, no cookies, no tracking, no build dependencies.

## Run locally

Open `index.html` in your browser or serve the folder via:

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080.

## GitHub Pages deployment

The repo includes `.github/workflows/pages.yml`. On pushes to `main` the action will configure GitHub Pages if allowed and deploy the site. If the run reports an API / Pages configuration error, visit **Repository → Settings → Pages → Build and deployment → GitHub Actions**, then rerun the workflow in **Actions**. GitHub Pages may take a short time to publish.

The project is designed for the GitHub Pages **project** URL `/VerityStory/`: all first-party assets use relative paths.

## Editorial policy

This is **not an official Verity website**. The original film is scripted fiction. Evidence categories are clearly displayed:
- **On-screen / published:** story elements or release facts.
- **Character claim:** statements a fictional character makes, not verified history.
- **Interpretive / fan theory:** community hypotheses or original critical analysis.

The site does not imply real AI is conscious, that a real rogue Verity exists, or that playable fan-made mod lore is automatically film canon. Sources are linked from the content and compiled in **Sources & credits**.
